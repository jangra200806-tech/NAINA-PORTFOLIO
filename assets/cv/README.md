# CV / Resume

Drop your CV here with this exact filename so the hero **Download CV** button works:

```
assets/cv/Naina-Jangra-CV.pdf
```

If you use a different filename or a Google Drive link, update this line in `index.html`:

```html
<a class="btn btn--ghost" href="assets/cv/Naina-Jangra-CV.pdf" download>
```

- Local file: `assets/cv/your-file.pdf`
- Google Drive: `https://drive.google.com/uc?export=download&id=FILE_ID` (remove the `download` attribute)
